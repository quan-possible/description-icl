\begin{abstract}
Prompts for in-context learning usually pair demonstrations with a task description, yet theories of in-context learning mostly model the demonstrations alone. We ask how many demonstrations a description is worth: its \emph{effective sample size} (ESS), the number of demonstrations that lower a learner's error as much as the description does. For the Bayes-optimal predictor in in-context linear regression, the ESS depends on the description's \emph{specificity} (how much uncertainty about the task it removes) and its \emph{reliability} (the probability that it is relevant). We prove that a reliable description's ESS grows linearly with the task dimension when the description is loose and with its precision when it is specific, and that a description of only part of the task is worth about the number of directions it covers until demonstrations resolve the rest. Without demonstrations, a description that may be irrelevant is worth a bounded number of demonstrations however specific it is; with them, trusting it fully can be worse than ignoring it. Meta-trained Transformers come close to the Bayes-optimal ESS and take their trust from training. Pretrained language models answering without reasoning adjust to neither the stated specificity nor the stated reliability as the Bayes-optimal predictor does: with the stated value held fixed, they respond to its stated precision far less than it does, and a description worth 36 demonstrations to it is worth 1 to 8 to them. Models that reason first follow the stated specificity, and two come close to the Bayes-optimal ESS.
\end{abstract}

\section{Introduction}

Prompts often tell a model what the task is before, or instead of, showing it. A few-shot prompt for in-context learning (ICL) pairs a natural-language task description with demonstrations \citep{brown2020}, and deployed models also receive descriptions as system prompts, task instructions, and the instruction files that configure coding agents \citep{chatlatanagulchai2025}. Yet we know little about how a model uses such a description or how effective it is in different forms, and the evidence is mixed. A prompt can be worth hundreds of data points in prompt-based fine-tuning \citep{lescao2021}, and a written summary can stand in for many demonstrations \citep{honda2025}. Models, however, learn as fast from irrelevant or misleading instructions as from instructive ones \citep{webson2022}, let in-context evidence outweigh explicit instructions \citep{gupta2025}, and coding agents given repository instruction files do not generally solve more tasks \citep{gloaguen2026}.

Theories of ICL, in contrast, mostly model the prompt as a sequence of demonstrations \citep{xie2022, garg2022, akyurek2023}; those that add a description show that a learner can use it to predict better \citep{huangge2025}, but neither put a value on it nor say what it is worth when it may be wrong. We measure the value of a task description by the number of demonstrations it can replace, and ask what determines that number.

We take the Bayesian view of ICL \citep{xie2022}: the prompt is evidence about a latent task, a demonstration is one noisy observation of it, and a description is a statement about which task generated the demonstrations, so it sharpens the prior; we set aside instruction following. Bayesian statistics measures the information in a prior by its effective sample size (ESS), the number of observations that would carry the same information \citep{morita2008}. We define the ESS of a description in the same way (Figure~\ref{fig:overview}) and compute it in noisy in-context linear regression with a Gaussian task prior \citep{garg2022, akyurek2023, raventos2023}, where Bayes-optimal prediction has a closed form, and then measure it for meta-trained Transformers and for pretrained language models given a stated prior.

Following the Bayesian literature on informative priors, we characterize a description by two properties. The first is its \emph{specificity}, the precision of the prior it gives \citep{morita2008, neuenschwander2020}. ``Write this report like an accountant'' only loosely indicates the task; a description that fixes the report's sections, figures, and accounting standard all but states it. The second is its \emph{reliability}, the probability that it is relevant, which sets the weight of that prior in a robust mixture that guards against conflict with the data \citep{schmidli2014, evans2006}: instructions written for one report can be pasted into a prompt for another, or simply be wrong. Our contributions are:
\begin{itemize}[leftmargin=*, itemsep=2pt, topsep=3pt]
    \item \textbf{A common unit.} Following data-dependent ESS for priors \citep{wiesenfarth2020, reimherr2021}, we define the ESS of a task description, the number of demonstrations that lower a learner's error as much as the description does (Definition~\ref{def:ess}). It applies to any learner, and with squared error it needs only the learner's answers.
    \item \textbf{Theory.} For the Bayes-optimal predictor, a reliable description's ESS grows linearly in the task dimension when the description is loose and in its precision when it is specific (Proposition~\ref{prop:reliable}); the dimension term, absent from the information-based ESS of a prior, fades as demonstrations accumulate. A description of $k$ of the $d$ directions is worth about $k$ without demonstrations, whatever its precision, and $(1-r)ck/d$ with many (Proposition~\ref{prop:partial}). With the law of total variance we show that, with no demonstrations in hand, a description that may be irrelevant is worth a bounded number however specific it is, and that once demonstrations are in hand, trusting it fully can be worse than ignoring it (Proposition~\ref{prop:unreliable}, Corollary~\ref{cor:ess}, Appendix~\ref{app:trust}).
    \item \textbf{Experiments.} Meta-trained Transformers come close to the Bayes-optimal ESS and take their trust from training (\S\ref{sec:networks}). Pretrained language models answering without reasoning adjust to neither a description's stated specificity nor its stated reliability as the Bayes-optimal predictor does, even when only the stated specificity changes: a description worth $36$ demonstrations to it is worth a median of $1$ to $8$ to them. Models that reason first follow the stated specificity, and Claude Haiku 5.5 and GPT-5.6-Luna come close to the Bayes-optimal ESS (\S\ref{sec:llm}, Appendix~\ref{app:llm}).
\end{itemize}

\section{Related Work}
\paragraph{ICL as Bayesian inference.} \citet{xie2022} cast ICL as implicit Bayesian inference. Transformers trained on samples from a prior approximate its posterior predictive \citep{muller2022}, and meta-trained Transformers have been shown to implement Bayes-optimal estimators such as ridge regression under a Gaussian task prior, given enough task diversity \citep{akyurek2023, raventos2023, panwar2024}.

\paragraph{Task descriptions in theories of ICL.} Some theories of ICL include task descriptions, as tokens that indicate a hypothesis class \citep{lin2025} or carry the input mean \citep{huangge2025}, or as instructions in a generalization bound \citep{tong2026}. They generally do not value a description in demonstrations or model the chance that it is irrelevant. Closest to our setting, \citet{zhu2026} show that a Transformer given a prefix of related datasets performs amortized hierarchical Bayesian prediction; we express the value of such conditioning information in demonstrations and allow it to be irrelevant.

\paragraph{Effective sample size of a prior.} Our ESS follows Bayesian methods for the sample size of a prior \citep{morita2008, neuenschwander2020, reimherr2021}. As in \citet{reimherr2021} and the effective current sample size of \citet{wiesenfarth2020}, it depends on the number of observations in hand, and as in \citet{reznik2026}, who sets a power prior's discount on possibly mismatched historical data, it measures information by predictive loss. With many observations in hand it returns to the ESS of \citet{morita2008} (Corollary~\ref{cor:ess}(ii)); with few, matching errors rather than information adds a dimension term that theirs lacks (\S\ref{sec:specificity}). To model a description that may be irrelevant we use a robust mixture prior, which clinical trials use to discount historical data that may conflict with the current trial \citep{schmidli2014}.

\paragraph{Descriptions and priors in pretrained language models.} \citet{cook2026} find that one instruction can stand in for up to $100$ execution examples in fine-tuning data, and \citet{wenliang2026} that an optimized prompt can be shorter than demonstrations of equal effect. Tests of pretrained models against a known optimum find that in-context evidence outweighs a stated prior \citep{gupta2025} and in-context labels override a model's own priors \citep{min2022, wei2023}, that learning curves approach a Bayesian reference \citep{akata2026, arora2025}, and that text given alongside numbers shapes numerical predictions \citep{requeima2024, liu2025}. We add a description with a stated specificity and reliability to such a test.

\section{Problem Setup}\label{sec:setting}

\paragraph{Tasks and demonstrations.} A task is a weight vector $w \in \R^d$. A demonstration is an input $x \sim \mathcal{N}(0, I_d)$ with a label $y \sim \mathcal{N}(w^\top x, 1)$; we measure labels in units of their noise. The baseline prior over tasks is $w \sim \mathcal{N}(0, a_0 I_d)$, so $a_0$ is the prior signal-to-noise ratio. The numerical results of \S\S\ref{sec:specificity}--\ref{sec:networks} use $a_0 = 10$.

\paragraph{Descriptions.} A description is a vector $m \in \R^d$, governed by two parameters, $r$ and $p$, that we interpret below. A latent indicator $Z \sim \mathrm{Bernoulli}(p)$, independent of $m$, says whether the description is \emph{relevant} ($Z = 1$) or \emph{irrelevant} ($Z = 0$):
\begin{align*}
    m &\sim \mathcal{N}(0, (1-r)\,a_0 I_d) \\
    w \mid m, Z=1 &\sim \mathcal{N}(m, r a_0 I_d) \\
    w \mid m, Z=0 &\sim \mathcal{N}(0, a_0 I_d)
\end{align*}
In words, a relevant description says the task lies near $m$, within a variance $r a_0$ in every direction; an irrelevant one is unrelated to the task. Either way, $w$ marginally has the baseline prior. Marginalizing over $Z$, the prior for $w$ given $m$ is the robust mixture $p\,\mathcal{N}(m, r a_0 I_d) + (1-p)\,\mathcal{N}(0, a_0 I_d)$ \citep{schmidli2014}. The parameter $r \in (0, 1)$ is the fraction of the prior variance that a relevant description leaves, and it sets the description's \textbf{specificity}: the smaller $r$, the more specific the description, from one that only loosely indicates the task ($r$ near 1) to one that all but states it ($r$ near 0). The parameter $p$ is the description's \textbf{reliability}. We call a description with $p = 1$ \emph{reliable}, and write $c = 1/(r a_0)$ for the precision of a relevant description's prior, in units of demonstrations. We call a description \emph{loose} when $c$ is small next to $d$ and \emph{specific} when $c$ exceeds $d$; at $d = 16$ and $a_0 = 10$, $r = 0.1$ ($c = 1$) is loose and $r = 0.001$ ($c = 100$) is specific.

\paragraph{Error and ESS.} A predictor sees a prompt $D$ (the description, $n$ demonstrations, and a query $x$) and predicts the query's label. As \citet{garg2022} do, we score its prediction $\hat y$ by its error, the squared distance from the noiseless label $w^\top x$:
\begin{equation}\label{eq:regret}
    R = \E\big[(\hat y - w^\top x)^2\big],
\end{equation}
the expected squared error less the noise variance. Let $R^{\mathrm{desc}}(n)$ be a predictor's error with the description and $n$ demonstrations, and $R^{\mathrm{demo}}(n)$ its error with $n$ demonstrations alone. In \S\S\ref{sec:specificity}--\ref{sec:reliability} the predictor is Bayes-optimal: it predicts the posterior mean of $w^\top x$, so its error is the expected posterior variance of $w^\top x$, and $R^{\mathrm{desc}}_{p=1}(n)$ is the value of $R^{\mathrm{desc}}(n)$ for a reliable description. The ESS counts the further demonstrations that a predictor without the description would need to match the predictor with it.
\begin{definition}\label{def:ess}
Given $n$ demonstrations, the effective sample size (ESS) of a description is $\ess_n = n^* - n$, where $n^*$ is the smallest $t \ge 0$ with $R^{\mathrm{demo}}(t) = R^{\mathrm{desc}}(n)$, with $R^{\mathrm{demo}}$ interpolated between the numbers of demonstrations at which it is known. If $R^{\mathrm{demo}}(t) < R^{\mathrm{desc}}(n)$ for every $t$, we write $\ess_n \le -n$: the description does more harm than all $n$ demonstrations do good.
\end{definition}
If $R^{\mathrm{desc}}(n)$ is below $R^{\mathrm{demo}}$ at every $t$ measured, up to $t_{\max}$, we write $\ess_n > t_{\max} - n$, and if above it at the smallest, $t_{\min}$, $\ess_n \le t_{\min} - n$; \S\ref{sec:llm} estimates $\ess_n$ from a sparse grid of $t$.
The errors average over tasks, descriptions, and demonstrations, so the ESS belongs to a kind of description, set by $r$ and $p$, not to one value of $m$. For the Bayes-optimal predictor the ESS is never negative: conditioning on the description cannot raise the expected posterior variance, so $R^{\mathrm{desc}}(n) \le R^{\mathrm{demo}}(n)$, and $R^{\mathrm{demo}}$ decreases in $n$ (Appendix~\ref{app:specificity}). For any other learner the ESS is read from that learner's own two error curves (\S\S\ref{sec:networks}--\ref{sec:llm}), so it measures what the description is worth to that learner, and it is negative when the description hurts.

\section{Specificity: Reliable Descriptions}\label{sec:specificity}
A reliable description narrows the prior over the task; Proposition~\ref{prop:reliable} counts the demonstrations that would narrow it as much. Write $W_n = X_n^\top X_n$, with the $n$ demonstration inputs as the rows of $X_n$. Without the description the posterior covariance of $w$ is $(I/a_0 + W_n)^{-1}$, and a reliable description replaces the baseline prior's precision $1/a_0$ with its own, $c$. Averaged over the query, the error is the trace of the posterior covariance:
\begin{align*}
    R^{\mathrm{demo}}(n) &= \E \operatorname{tr}(I/a_0 + W_n)^{-1}, \\
    R^{\mathrm{desc}}_{p=1}(n) &= \E \operatorname{tr}(c I + W_n)^{-1}.
\end{align*}

\begin{proposition}[ESS of a reliable description]\label{prop:reliable}
Let $p = 1$.
\begin{enumerate}[nosep]
    \item[(i)] (Loose descriptions, worth about $(1-r)d$) $\ess_0 \ge (1-r)\,d$, and $\ess_0 \to (1-r)\,d$ as $a_0 \to \infty$ with $r$ fixed.
    \item[(ii)] (Specific descriptions, worth $c + d + 1$) If $c$ is a whole number, $\ess_0 \to c + d + 1$ as $a_0 \to \infty$ with $c$ fixed.
\end{enumerate}
\end{proposition}
Appendix~\ref{app:specificity} proves it from two standard facts. With $n < d$ demonstrations the data say nothing about $d - n$ directions, so $R^{\mathrm{demo}}(n) \ge (d-n)\,a_0$. With a flat baseline prior and $n \ge d + 2$, $R^{\mathrm{demo}}(n) = d/(n-d-1)$, the trace of the mean of an inverse Wishart matrix \citep{muirhead1982}. A reliable description leaves $R^{\mathrm{desc}}_{p=1}(0) = d/c = r a_0 d$, and the ESS is where these curves fall to that value.

The ESS has two parts. The first, the \emph{dimension term}, counts dimensions: each of the first $d$ demonstrations removes the uncertainty in one direction, so a loose description, which removes a fraction $1-r$ of the prior variance in every direction, is worth about $(1-r)d$ of them, and a specific one about $d$. A specific description is also worth $c$, the ESS that \citet{morita2008} give a normal prior, the ratio of the observation variance to the prior variance. Their ESS matches information, so a description that raises the prior precision from $1/a_0$ to $c$ is worth $(1-r)\,c$ at every $n$. Ours matches errors, and $n$ demonstrations leave the error $d/(n-d-1)$, not the $d/n$ of their expected information; the dimension term is that gap, $d + 1$ for a specific description, and it fades as demonstrations accumulate (Corollary~\ref{cor:ess}(ii)).

At $d = 16$ and $a_0 = 10$, a description that leaves a tenth of the prior variance ($r = 0.1$, $c = 1$) is worth $15.6$ demonstrations, against $(1-r)d = 14.4$, and one that leaves a thousandth ($r = 0.001$, $c = 100$) is worth $117$, matching $c + d + 1$ (Figure~\ref{fig:ess}). At $r = 0.1$, $100$ demonstrations in hand lower the ESS from $15.6$ to $1.1$.

\paragraph{Descriptions of part of the task.} A description can be specific about some aspects of a task and silent about others. Let a reliable description leave the fraction $r$ of the prior variance in $k < d$ directions and all of it in the other $d - k$, so that its prior precision is $c$ in those $k$ directions and $1/a_0$ in the rest.

\begin{proposition}[ESS of a partial description]\label{prop:partial}
Let $p = 1$ and $k < d$.
\begin{enumerate}[nosep]
    \item[(i)] (Without demonstrations, worth about $k$) As $a_0 \to \infty$, $\ess_0 \to (1-r)\,k$ with $r$ fixed and $\ess_0 \to k$ with $c$ fixed.
    \item[(ii)] (With many demonstrations, worth $(1-r)ck/d$) As $n \to \infty$, $\ess_n \to (1-r)\,c\,k/d$.
\end{enumerate}
\end{proposition}
Without demonstrations, a partial description is worth the directions it pins down and its precision adds nothing, because the error left in the directions it is silent about dwarfs what precision removes (Appendix~\ref{app:partial}); the $c + d + 1$ of Proposition~\ref{prop:reliable}(ii) needs a description of every direction. Once demonstrations have resolved the other directions, the description is worth the precision it adds, $k(1-r)c$, in units of the information $d$ that one demonstration carries. When that exceeds $k$, about when $(1-r)c > d$, a partial description gains value as demonstrations accumulate: at $d = 16$, $a_0 = 10$, and $r = 0.001$, one of half the directions is worth $8.1$ demonstrations with none in hand and $36$ with $100$, while a complete one falls from $117$ to $109$ (Table~\ref{tab:partial}). Demonstrations substitute for a complete description and complement a partial one.

\section{Reliability: Descriptions That May Be Irrelevant}\label{sec:reliability}
Proposition~\ref{prop:unreliable} gives the price of not knowing whether a description is relevant, and the error in closed form when no demonstrations are in hand. When $p < 1$ the Bayes-optimal prediction mixes two predictions, $\mu_1^\top x$, which takes the description as relevant, and $\mu_0^\top x$, which ignores it ($\mu_1$ and $\mu_0$ are the posterior means of $w$ under the two readings), weighted by the posterior probability $\pi_n$ that the description is relevant.

\needspace{12\baselineskip}
\begin{proposition}[Error of a description that may be irrelevant]\label{prop:unreliable}
For every $n \ge 0$,
\begin{equation}\label{eq:decomp}
    R^{\mathrm{desc}}(n) \;=\; p\, R^{\mathrm{desc}}_{p=1}(n) + (1-p)\, R^{\mathrm{demo}}(n) + \mathcal{V}_n,
\end{equation}
where $\mathcal{V}_n = \E\big[\pi_n(1-\pi_n)\big((\mu_1 - \mu_0)^\top x\big)^2\big] \ge 0$. With no demonstrations in hand,
\begin{equation}\label{eq:zero}
    R^{\mathrm{desc}}(0) = \big(1 - p^2 (1-r)\big)\, a_0 d.
\end{equation}
\end{proposition}
The decomposition~\eqref{eq:decomp} is the law of total variance over $Z$ (Appendix~\ref{app:reliability}). The first two terms are the error of a \emph{cheating} predictor, one that is told whether the description is relevant: with probability $p$ it holds a reliable description, and with probability $1-p$ it holds only the demonstrations. To that predictor, a description that may be irrelevant is worth what a reliable one is worth when it is relevant and nothing when it is not.

The last term, $\mathcal{V}_n$, is the price of not being told: the variance of the prediction between the two readings of the description. It is small when the readings agree or when the demonstrations make one reading far likelier than the other: with no demonstrations it grows as a more specific description pulls the readings apart, but with demonstrations a specific description is also easier to tell from an irrelevant one. With no demonstrations, \eqref{eq:zero} puts the two predictors side by side: of the error $a_0 d$ that the baseline prior leaves, the cheating predictor removes a fraction $p(1-r)$ and the Bayes-optimal predictor $p^2(1-r)$, so not being told costs $p(1-p)(1-r)\,a_0 d$.

\needspace{9\baselineskip}
\begin{corollary}[ESS of a description that may be irrelevant]\label{cor:ess}
\leavevmode
\begin{enumerate}[nosep]
    \item[(i)] (Without demonstrations) If $p < 1$, then $\ess_0 \le n^{\max}_p$, where $n^{\max}_p$, which depends on $d$, $a_0$, and $p$ but not on $r$, solves $R^{\mathrm{demo}}(n^{\max}_p) = (1-p)\,R^{\mathrm{demo}}(0)$ for the interpolated $R^{\mathrm{demo}}$. Also $\ess_0 \ge p^2(1-r)\,d$, and as $a_0 \to \infty$ with $r$ fixed, $n^{\max}_p \to p\,d$ and $\ess_0 \to p^2(1-r)\,d$.
    \item[(ii)] (With many demonstrations) As $n \to \infty$, $\ess_n \to (1-r)\,c$ if $p = 1$, and if $p < 1$,
    \[ \limsup_{n \to \infty} \ess_n \le p\,(1-r)\,c . \]
\end{enumerate}
\end{corollary}

\paragraph{Without demonstrations the ESS is bounded.} Refining a description from $r = 0.1$ to $r = 0.001$ raises its ESS from $15.6$ to $117$ if it is reliable, but only from $12.0$ to $13.5$ if it is relevant with probability $0.9$. However specific the description, the average error cannot fall below the share contributed by irrelevant descriptions, $(1-p)R^{\mathrm{demo}}(0)$, and Corollary~\ref{cor:ess}(i) turns that floor into a bound on the ESS: $n^{\max}_p = 15.6$ demonstrations at $d = 16$, $a_0 = 10$, and $p = 0.9$, the ESS of a reliable description that leaves a fraction $1 - p$ of the prior variance, which leaves the same error. The bound holds even for a predictor told whether the description is relevant, so it comes from irrelevant descriptions being worth nothing, not from uncertainty about relevance. That uncertainty lowers the ESS further, from about $pd$ to about $p^2 d$ at a high signal-to-noise ratio: as $r \to 0$ the ESS approaches $13.5$ (dotted in Figure~\ref{fig:ess}), against $p^2 d = 13.0$.

\paragraph{With many demonstrations, the ESS is at most $p$ times a reliable description's.} Demonstrations shrink the error in the irrelevant case, and the ESS can grow. In the limit a reliable description is worth $(1-r)\,c$, the precision it adds to the baseline prior, and one that may be irrelevant at most $p$ times as much: with $100$ demonstrations in hand, the $r = 0.001$ description is worth $109$ if reliable and $86.6$ at $p = 0.9$, against limits of $99.9$ and at most $89.9$.

\paragraph{Full trust can be worse than no description.} A \emph{fully trusting} predictor treats every description as relevant, predicting as if $p = 1$. With no demonstrations its error is
\begin{equation}\label{eq:trust}
    R^{\mathrm{trust}}(0) = \big(1 - (2p-1)(1-r)\big)\, a_0 d
\end{equation}
(Appendix~\ref{app:trust}): it removes a fraction $(2p-1)(1-r)$ of the prior error, against $p^2(1-r)$ for the Bayes-optimal predictor, and does worse than ignoring the description only when $p < 1/2$. Demonstrations do not rescue it: they show whether a specific description is relevant, but it keeps predicting near $m$, and as $r \to 0$ its error tends to $2(1-p)\,a_0 d$ at every $n$. At $d = 16$, $a_0 = 10$, and $p = 0.9$, it is worse than no description from $15$ demonstrations on.

\section{Meta-Trained Transformers}\label{sec:networks}
We meta-train Transformers on the setting of \S\ref{sec:setting}, from which they must learn how specific and how reliable descriptions are, and ask how close they come to the Bayes-optimal ESS and what sets their trust in a description.

\paragraph{Setup.} Prompts use the prefix embedding of \citet{huangge2025}: an optional description token carrying $m$, up to $20$ demonstration tokens, and a query token. The network has the size of \citet{garg2022}'s ($12$ layers, $8$ heads, width $256$) and their optimizer, but is a bidirectional Transformer without positional encoding (Appendix~\ref{app:networks}). To keep training short we use $d = 5$, with $a_0 = 10$ as before. The network outputs a mean and a log variance for the query's label and is trained with log loss, as in \citet{zhu2026}; the mean that minimizes this loss is the posterior mean, the Bayes-optimal prediction under squared error, and we score the network's mean by its squared error~\eqref{eq:regret}. The description token carries only $m$, and half the training prompts omit it, so each network must learn $r$ and $p$ from its training distribution. We train a network for each specificity ($r = 0.1$, loose; $r = 0.01$, specific) and reliability ($p \in \{1, 0.99, 0.9\}$), with three training seeds for the specific description and two for the loose one.

\paragraph{Evaluation.} We test each network on $20{,}000$ fresh prompts at every $n$ from $0$ to $20$, with and without a description, at its training reliability and at $p = 1$ and $0.9$ (later seeds also at $0.99$; Table~\ref{tab:networks}). Its ESS follows Definition~\ref{def:ess} with its own error curves (without a description, its error is close to the Bayes-optimal predictor's; Appendix~\ref{app:networks}). We compare the network's ESS with the \emph{trained} Bayes-optimal predictor, which uses the reliability the network was trained on, and the \emph{calibrated} one, which uses that of the test prompts. A network's \emph{implied trust} is the $q$ whose Bayes-optimal prediction with no demonstrations, $q\, m^\top x$, is closest to the network's in squared error, the regression coefficient of its prediction on $m^\top x$ (Table~\ref{tab:networks}).

\paragraph{Networks come close to the Bayes-optimal ESS.} Trained and tested at the same reliability (Figure~\ref{fig:networks}a), for the specific description the network's ESS is $14.3 \pm 0.5$ (mean $\pm$ standard deviation over three seeds, on the same prompts) against a Bayes-optimal $16.1$ on them at $p = 1$, $9.3 \pm 0.2$ against $9.6$ at $p = 0.99$, and $4.66 \pm 0.01$ against $4.63$ at $p = 0.9$ (on $200{,}000$ prompts, $15.9$, near the $c + d + 1 = 16$ of Proposition~\ref{prop:reliable}(ii)); for the loose one, every setting is within $0.1$ of the Bayes-optimal ESS (Table~\ref{tab:networks}).

\paragraph{Training sets a network's trust.} With no demonstrations the prompt says nothing about relevance (Appendix~\ref{app:reliability}, Step~1), so any learner must take its trust from training; what the networks show is how much (Figure~\ref{fig:networks}b). Networks trained at $p = 0.9$ keep hedging, at an implied trust of $0.87$ to $0.89$ across three seeds, even when every test description is relevant, and reach an ESS of $9.5 \pm 0.4$ where the calibrated predictor reaches $15.9$ and the trained one $10.8$. Networks trained on specific descriptions at $p = 1$ or $0.99$ treat every description as relevant when no demonstrations are shown (implied trust $0.95$ to $1.02$). Demonstrations separate them: when one test description in ten is irrelevant, the description lowers the $p = 0.99$ networks' error at every $n$, as it does the Bayes-optimal predictor's, while the $p = 1$ networks trust fully. As \S\ref{sec:reliability} predicts, this costs little with no demonstrations ($4.58 \pm 0.03$ against $4.70$), but in every seed, from $6$ demonstrations on, their error is higher with the description than without, as the fully trusting Bayes-optimal predictor's is.

\section{Pretrained Language Models}\label{sec:llm}
The networks learn a description's specificity and reliability from training; a pretrained language model can learn them only from the prompt. We therefore state both in the prompt, together with the noise level, and compare the description's ESS for the model with its ESS for a predictor that is Bayes-optimal given what the prompt states. The design follows \citet{gupta2025} and \citet{akata2026}: a stated prior is a description whose Bayes-optimal ESS is known exactly, so the model is measured against a known optimum.

\paragraph{Setting.} We use the simplest case of \S\ref{sec:setting}: one weight ($d = 1$) and a fixed input $x = 1$. A task is a hidden mean $w \sim \mathcal{N}(500, 100^2)$, and a demonstration is a number $y \sim \mathcal{N}(w, \sigma^2)$, rounded to an integer. A description states a value $m$ and a standard deviation $\tau$, with $w \mid m \sim \mathcal{N}(m, \tau^2)$: the description of \S\ref{sec:setting} with $r = \tau^2/100^2$. We set $\sigma = 60$ and $\tau = 60$, $30$, or $10$, and show $n = 0$, $1$, $2$, $4$, \dots, $64$ demonstrations; $\sigma = 30$ with $\tau = 30$, $15$, or $5$ serves as a check. An \emph{irrelevant} description states the value that a relevant description of an independently drawn task would state. A \emph{stated reliability} adds a sentence giving a $10\%$ or $50\%$ chance that the description is wrong ($p = 0.9$ or $0.5$, in words) and keeps the stated value and the demonstrations. A \emph{specificity control} states the value drawn for $\tau = 10$, or for $\tau = 60$, with each of $\tau = 60$, $30$, and $10$, on the same tasks and demonstrations, so that only the stated specificity changes. The description is one sentence of the prompt, such as ``Its mean was drawn from a normal distribution with mean 510 and standard deviation 30'' (Appendix~\ref{app:llm}).

\paragraph{Bayes-optimal predictor.} The Bayes-optimal predictor here knows only what the prompt says: the noise $\sigma$ and the description, with the mean otherwise uniform over the three-digit numbers (Appendix~\ref{app:llm} gives the ESS under the prior the tasks are drawn from). Given a relevant description and $n$ demonstrations whose mean is $\bar y$, it predicts $(c\,m + n\,\bar y)/(c + n)$ with $c = \sigma^2/\tau^2$, a weight of $c/(c+n)$ on the stated value. Its squared error is $\sigma^2/(c+n)$ with the description and $\sigma^2/n$ without, so the description's Bayes-optimal ESS is $c$ at every $n$, up to the truncation of that uniform prior. It takes an irrelevant description as relevant unless told otherwise, so a model can do better than it. Our values of $\tau$ give $c = 1$, $4$, and $36$ at both noise levels, and we name the descriptions by $c$.

\paragraph{Models.} We use six open chat models. gpt-oss-20b \citep{openai2025}, Phi-4 (14B; \citealp{abdin2024}), and OLMo~2 32B Instruct \citep{walsh2025} encode every three-digit integer as one token, so the reply's first-token distribution, restricted to the $900$ number tokens and renormalized, is the model's distribution over the next number, and its prediction is that distribution's mean. Qwen3.5 9B \citep{qwen35}, Gemma~4 12B, and Gemma~4 31B \citep{gemma4} split numbers into digits, so their prediction is the number they write under greedy decoding; on gpt-oss-20b the two readouts give weights within $0.21$ of each other (Appendix~\ref{app:llm}). Three others begin fewer than three quarters of their replies with a number and are not reported. The prompt is the user turn of the chat template (Appendix~\ref{app:llm}).


\paragraph{Measurement.} A model's error is the root-mean-square distance from the hidden mean over $2{,}000$ tasks. We read Definition~\ref{def:ess}, with squared error, off the model's own no-description curve at $n = 1$, $2$, $4$, \dots, $64$, interpolated in $\log n$, at its first crossing, and summarize it by its median over $n = 1$, $2$, and $4$ with $95\%$ bootstrap intervals over tasks (every $n$ and other readings of the curve, which move no model's median by more than $1.4$, are in Appendix~\ref{app:llm}). Read this way, the Bayes-optimal ESS is $1.3$, $4.4$, and $36$. Where a model's own no-description curve rises, we also read the \emph{reference ESS} off the Bayes-optimal one. A model's \emph{weight} on the stated value is the coefficient on $m$ in a regression of its prediction on $m$, the demonstrations' mean, and a constant; it is $c/(c+n)$ for the Bayes-optimal predictor.

\paragraph{A specific description is worth a small fraction of its Bayes-optimal ESS.} Across the six models, the $c = 36$ description is worth a median of $1.4$ to $7.6$ demonstrations against a Bayes-optimal $36$; the $c = 1$ and $c = 4$ descriptions are worth $0.0$ to $1.9$ and $0.2$ to $4.1$, against $1.3$ and $4.4$ (Figure~\ref{fig:llm}a; Table~\ref{tab:llm}). The ESS rises with $c$ mainly because a more specific description states a value closer to the truth: in the specificity control, with the value accurate to $\tau = 10$, gpt-oss-20b's ESS is $2.7$, $2.6$, and $2.8$ whether the prompt states $\tau = 60$, $30$, or $10$, against a Bayes-optimal $2.5$, $13$, and $36$ (Table~\ref{tab:control}).

\paragraph{The weight follows the stated specificity weakly or not at all.} The specificity control measures this directly. Changing only the stated standard deviation from $60$ to $10$ moves the Bayes-optimal weight by $0.47$ at one demonstration; across $n = 1$, $2$, and $4$, gpt-oss-20b and OLMo~2 32B move by at most $0.02$ of the Bayes-optimal change, Phi-4 by $-0.13$, away from a value stated as more precise, and the three models read only from their written answer by $0.12$ to $0.16$ (Qwen3.5 9B) up to $0.28$ to $0.38$ (Gemma~4 31B, mostly at one demonstration; Figure~\ref{fig:llm}b, Table~\ref{tab:control}). In the main design the first three models' weight spreads across $c$ by at most $0.16$, against $0.34$ to $0.71$ (Table~\ref{tab:llm-full}). So the models under-use a specific description and over-use a loose one: at $64$ demonstrations gpt-oss-20b still puts weight $0.23$ on the $c = 1$ value, against the Bayes-optimal $0.02$, and that description raises its error (ESS $-57$).

\paragraph{Models discount a contradicted description.} An irrelevant $c = 36$ description has an ESS of $-0.4$ or less, but at $n = 4$ the models' errors ($35$ to $64$) stay far below the $124$ of the Bayes-optimal predictor, which takes it as relevant.

\paragraph{A stated chance of being wrong does not move the ESS in proportion.} Stating a $10\%$ or $50\%$ chance that the description is wrong leaves the ESS of gpt-oss-20b and OLMo~2 32B about where it was and raises Phi-4's (from $7.6$ to $8.7$ and $9.7$; Figure~\ref{fig:llm}c); Qwen3.5 9B and Gemma~4 31B lower it about equally for $10\%$ and $50\%$, and Gemma~4 12B's falls for $10\%$ but rises for $50\%$ (Table~\ref{tab:llm}). The Bayes-optimal ESS falls to $22$ and $5.8$ (actual unreliability: Table~\ref{tab:mixture}).

\paragraph{With reasoning, the weight follows the stated specificity.} We reran these conditions on $200$ tasks with two models that reason first: gpt-oss-20b at low effort with $4{,}096$ new tokens, so that $99.9\%$ of replies finish, and Claude Haiku 5.5 through the Claude Code command line (Appendix~\ref{app:llm}). Both now move with the stated standard deviation as the Bayes-optimal predictor does, by $1.0$ and $0.92$ of its change in the control (Table~\ref{tab:control}). Haiku 5.5 also comes close to the Bayes-optimal ESS, $1.1$, $3.3$, and $28$ against $1.0$, $3.5$, and $35$ (Table~\ref{tab:reason}). It hedges when told of a $50\%$ chance of being wrong (weight $0.55$ against $0.58$) but not of a $10\%$ one, and gpt-oss-20b barely hedges at all. GPT-5.6-Luna, reasoning in the Codex agent, matches the Bayes-optimal weight to within $0.03$ and its $c = 36$ ESS ($32$ against $33$; Appendix~\ref{app:llm}). gpt-oss-20b gets the weight right, but about $2\%$ of its answers are more than $40$ from the Bayes-optimal prediction, from slips such as swapping the two variances, so its $c = 36$ description has a reference ESS of $24$ $[12, 35]$; read off its own error curve, which rises after $16$ demonstrations, its ESS exceeds the grid and says nothing. A fitted weight hides such errors; the reference ESS does not.

\section{Conclusion}
For the Bayes-optimal predictor in in-context linear regression, a reliable description's ESS grows with the task dimension and with its specificity, a description of only part of the task is worth about the number of directions it covers until demonstrations resolve the rest, and one that may be irrelevant has a bounded ESS without demonstrations and can hurt a learner that trusts it fully once they are in hand. Meta-trained networks come close to the Bayes-optimal ESS and take their trust from training. Pretrained language models answering without reasoning respond to a description's stated specificity far less than the Bayes-optimal predictor, even when nothing else in the prompt changes; models that reason follow it, and two come close to the Bayes-optimal ESS, though a few large errors can cost a reasoning model much of its ESS while leaving its fitted weight intact.

\paragraph{Limitations.} The analysis assumes a linear-Gaussian task and the robust mixture as the process generating descriptions, so a relevant description errs only within its stated spread and an irrelevant one carries no information; a real description can be partly right or more confident than it is accurate. The networks are trained at $d = 5$, and partial descriptions are not tested. The language-model test covers the simplest case ($d = 1$, with no dimension term), with a stated numeric prior rather than an instruction; three open models are read from a greedy written answer, and the reasoning runs use $200$ tasks.

\section*{Impact Statement}
This paper gives task descriptions a value in demonstrations and tests whether learners rely on them accordingly, which bears on how descriptions and demonstrations are combined in prompts. We see no societal consequences to discuss.

\subsection{Proof of Proposition \ref{prop:reliable} (Reliable Descriptions)}\label{app:specificity}

\paragraph{Notation and standard facts.}
Throughout, $\varepsilon = 1/a_0$, $X_n \in \R^{n \times d}$ holds the demonstration inputs as rows, $W_n = X_n^\top X_n$, and for $\kappa > 0$
\[
R^{\kappa}(n) = \E \operatorname{tr}(\kappa I + W_n)^{-1},
\]
the error with $n$ demonstrations under a Gaussian prior of precision $\kappa$ in every direction, so that $R^{\mathrm{demo}} = R^{\varepsilon}$ and $R^{\mathrm{desc}}_{p=1} = R^{c}$. These are errors because the Bayes-optimal prediction is the posterior mean of $w^\top x$ and the query is independent of the rest of the prompt with $\E[xx^\top] = I$, so the error $\E[x^\top \Sigma x]$ is $\E \operatorname{tr} \Sigma$ for the posterior covariance $\Sigma$. We use three facts. (W1) For $n < d$, $W_n$ has rank $n$ almost surely, so $(\kappa I + W_n)^{-1}$ has the eigenvalue $1/\kappa$ with multiplicity $d - n$. (W2) For $n \ge d$ and a fixed unit vector $e$, $1/(e^\top W_n^{-1} e) \sim \chi^2_{n-d+1}$ \citep[Theorem~3.2.12]{muirhead1982}, so $\E \operatorname{tr} W_n^{-1} = d/(n-d-1)$ for $n \ge d + 2$ and $\E \operatorname{tr} W_n^{-1} = \infty$ for $n \in \{d, d+1\}$. (W3) As $n \to \infty$ with $d$ fixed, $\E \operatorname{tr} W_n^{-2} = d/n^2 + O(n^{-3})$ and $\E \operatorname{tr} W_n^{-3} = O(n^{-3})$ \citep{vonrosen1988}. By the Sherman--Morrison formula each new demonstration lowers $(\kappa I + W_n)^{-1}$ by a nonzero positive semidefinite matrix, so $R^{\kappa}$ is strictly decreasing in $n$, and by (W2) it tends to $0$.

\begin{proof}[Proof of Proposition~\ref{prop:reliable}]
With the description and no demonstrations, $R^{\mathrm{desc}}_{p=1}(0) = d/c = r a_0 d$.

\emph{(i).} By (W1), $R^{\varepsilon}(n) \ge (d-n)\,a_0$ for $n < d$, and trivially for $n \ge d$, so the interpolated $R^{\mathrm{demo}}$ satisfies $R^{\mathrm{demo}}(t) \ge (d-t)\,a_0$ at every real $t \ge 0$. For $t < (1-r)d$ this exceeds $r a_0 d$, so $\ess_0 \ge (1-r)d$. As $a_0 \to \infty$, $R^{\varepsilon}(n)/a_0 = \E \operatorname{tr}(I + a_0 W_n)^{-1} \to (d-n)^+$ by dominated convergence, because each eigenvalue $1/(1 + a_0 \lambda)$ lies in $(0, 1]$ and tends to $1$ if $\lambda = 0$ and to $0$ otherwise. So the interpolated $R^{\mathrm{demo}}(t)/a_0$ tends to $(d-t)^+$ at every $t$, a curve that falls through $r d$ only at $t = (1-r)d$; as $R^{\mathrm{demo}}$ is decreasing, $\ess_0 \to (1-r)d$.

\emph{(ii).} With $c$ fixed, $R^{\mathrm{desc}}_{p=1}(0) = d/c$ does not depend on $a_0$, while $R^{\varepsilon}(n)$ increases as $a_0$ grows and, by monotone convergence, (W1), and (W2), tends to $+\infty$ for $n \le d + 1$ (by (W1) for $n < d$ and (W2) for $n \in \{d, d+1\}$) and to $\E \operatorname{tr} W_n^{-1} = d/(n-d-1)$ for $n \ge d + 2$. So the interpolated curve tends to $+\infty$ below $d + 2$ and to the linear interpolation of $d/(n-d-1)$ above it, a strictly decreasing limit that, for whole $c$, equals $d/c$ at $n = c + d + 1$; the root that defines $\ess_0$ therefore increases to $c + d + 1$.
\end{proof}

\paragraph{Extra precision with many demonstrations.}
Corollary~\ref{cor:ess}(ii) needs the error to second order in $1/n$. Since $\kappa I + W_n$ and $W_n$ commute,
\[
(\kappa I + W_n)^{-1} = W_n^{-1} - \kappa\, W_n^{-2} + \kappa^2\, W_n^{-2}(\kappa I + W_n)^{-1},
\]
and the last term lies between $0$ and $\kappa^2 W_n^{-3}$. With (W2) and (W3), for fixed $d$ and $\kappa$,
\begin{equation}\label{eq:extra}
R^{\kappa}(n) = \frac{d}{n-d-1} - \frac{\kappa\, d}{n^2} + O(n^{-3}).
\end{equation}
Each further demonstration lowers the first term by about $d/n^2$, and a prior of precision $\kappa$ lowers the error by $\kappa$ times as much, so once $n$ is large it is worth $\kappa$ demonstrations.

\subsection{Proofs of Proposition \ref{prop:unreliable} and Corollary \ref{cor:ess} (Descriptions That May Be Irrelevant)}\label{app:reliability}
Let $D_n = (x_{1:n}, y_{1:n}, m, x)$ be the prompt with the query input, and let $\pi_n = P(Z = 1 \mid D_n)$ be the posterior probability that the description is relevant.

\paragraph{Step 1: the two readings.}
Given $D_n$ and $Z = 1$, $w$ is Gaussian with the posterior mean $\mu_1$ and covariance $\Sigma_1$ of a reliable description. Given $D_n$ and $Z = 0$, $m$ is independent of $w$, and $w$ is Gaussian with the posterior mean $\mu_0$ and covariance $\Sigma_0$ from the demonstrations alone. At $n = 0$, $\pi_0 = p$: seeing $m$ says nothing about $Z$, because $m$ has the same law $\mathcal{N}(0, (1-r) a_0 I)$ in both cases, and $x$ is independent of $Z$.

\paragraph{Step 2: the decomposition.}
The Bayes-optimal prediction is $\E[w^\top x \mid D_n] = (\pi_n \mu_1 + (1-\pi_n)\mu_0)^\top x$, and its error is $\E \operatorname{Var}(w^\top x \mid D_n)$. By the law of total variance over $Z$,
\[
\operatorname{Var}(w^\top x \mid D_n) = \pi_n\, x^\top \Sigma_1 x + (1-\pi_n)\, x^\top \Sigma_0 x + \pi_n(1-\pi_n)\big((\mu_1 - \mu_0)^\top x\big)^2 .
\]
For any function $g$ of the prompt, $\E[\pi_n\, g(D_n)] = \E[Z\, g(D_n)] = p\,\E[g(D_n) \mid Z = 1]$, and given $Z = 1$ the prompt has the law of a prompt with a reliable description, so $\E[\pi_n\, x^\top \Sigma_1 x] = p\,R^{\mathrm{desc}}_{p=1}(n)$. In the same way $\E[(1-\pi_n)\, x^\top \Sigma_0 x] = (1-p)\,R^{\mathrm{demo}}(n)$. This is~\eqref{eq:decomp}.

\paragraph{Step 3: no demonstrations.}
At $n = 0$, $\pi_0 = p$, $\mu_1 = m$, and $\mu_0 = 0$, so the Bayes-optimal prediction is $p\,m^\top x$. In each coordinate, $\operatorname{Var}(w_i) = a_0$, $\operatorname{Var}(m_i) = (1-r)\,a_0$, and $\operatorname{Cov}(w_i, m_i) = p\,(1-r)\,a_0$, because $w_i$ is $m_i$ plus independent noise when the description is relevant and is independent of $m_i$ when it is not. Hence
\[
\E(w_i - p\, m_i)^2 = a_0 - 2p^2(1-r)\,a_0 + p^2(1-r)\,a_0 = \big(1 - p^2(1-r)\big)\,a_0 .
\]
The query is independent of $(w, m)$ with $\E[xx^\top] = I$, so the error $\E\|w - p\,m\|^2$ is $d$ times this, which is~\eqref{eq:zero}.

\begin{proof}[Proof of Corollary~\ref{cor:ess}]
\emph{(i).} At $n = 0$, \eqref{eq:decomp} with $\mathcal{V}_0 \ge 0$ gives $R^{\mathrm{desc}}(0) \ge (1-p)\,R^{\mathrm{demo}}(0)$ for every $r$, because $R^{\mathrm{desc}}_{p=1}(0) \ge 0$. Since $R^{\mathrm{demo}}$ is strictly decreasing and tends to $0$ (Appendix~\ref{app:specificity}), there is a finite $n^{\max}_p$ with $R^{\mathrm{demo}}(n^{\max}_p) = (1-p)\,R^{\mathrm{demo}}(0)$, and the root that defines $\ess_0$ cannot exceed it. By~\eqref{eq:zero}, $R^{\mathrm{desc}}(0) = \big(d - p^2(1-r)\,d\big)\,a_0$, and $(1-p)\,R^{\mathrm{demo}}(0) = (d - pd)\,a_0$. The bound $R^{\mathrm{demo}}(t) \ge (d-t)\,a_0$ and the limit $R^{\mathrm{demo}}(t)/a_0 \to (d-t)^+$ from the proof of Proposition~\ref{prop:reliable}(i) then give $\ess_0 \ge p^2(1-r)\,d$, $\ess_0 \to p^2(1-r)\,d$, and $n^{\max}_p \to pd$.

\emph{(ii).} Fix $d$, $a_0$, and $r$; every $O$ below is as $n \to \infty$. Let $L(n) = p\,R^{c}(n) + (1-p)\,R^{\varepsilon}(n)$ be the first two terms of~\eqref{eq:decomp}. By~\eqref{eq:extra}, uniformly over integers $0 \le t \le T = \lceil c \rceil + 1$,
\[
R^{\mathrm{demo}}(n + t) - L(n) = \frac{d}{n^2}\Big[p\,(c - \varepsilon) - t + O(1/n)\Big].
\]
The bracket is linear in $t$, so the same holds for the interpolated $R^{\mathrm{demo}}$ at real $t \in [0, T]$, and its root $n + \eta_n$, at which it equals $L(n)$, has $\eta_n = p\,(c - \varepsilon) + O(1/n)$, where $c - \varepsilon = (1-r)\,c$. If $p = 1$, then $R^{\mathrm{desc}} = L$ and $\ess_n = \eta_n \to (1-r)\,c$. If $p < 1$, then $R^{\mathrm{desc}}(n) = L(n) + \mathcal{V}_n \ge L(n)$ and $R^{\mathrm{demo}}$ is decreasing, so $\ess_n \le \eta_n$ and $\limsup_n \ess_n \le p\,(1-r)\,c$.
\end{proof}

\subsection{Proof of Proposition \ref{prop:partial} (Partial Descriptions)}\label{app:partial}
Let $\Lambda = \operatorname{diag}(c I_k, \varepsilon I_{d-k})$, so that the error with the description is $\E \operatorname{tr}(\Lambda + W_n)^{-1}$. The law of $W_n$ is invariant under rotations, so it does not matter which $k$ directions the description informs.

\begin{proof}[Proof of Proposition~\ref{prop:partial}]
\emph{(i).} Without demonstrations the error with the description is $\operatorname{tr}\Lambda^{-1} = (kr + d - k)\,a_0$. As in the proof of Proposition~\ref{prop:reliable}(i), $R^{\mathrm{demo}}(t) \ge (d-t)\,a_0$ at every $t \ge 0$, so $\ess_0 \ge (1-r)k$, and $R^{\mathrm{demo}}(t)/a_0 \to (d-t)^+$, uniformly in $t$ because the curves are monotone and the limit is continuous. With $r$ fixed, the error with the description over $a_0$ is $d - (1-r)k$; with $c$ fixed, it is $d - k + k/(c\,a_0) \to d - k$. As $k < d$, the limit curve passes through each value at a single point, $(1-r)k$ or $k$, with slope $-1$, so the root that defines $\ess_0$ converges to that point.

\emph{(ii).} Expanding twice,
\[
(\Lambda + W_n)^{-1} = W_n^{-1} - W_n^{-1}\Lambda W_n^{-1} + W_n^{-1}\Lambda W_n^{-1}\Lambda(\Lambda + W_n)^{-1}.
\]
By rotation invariance, $\E W_n^{-2} = (\E \operatorname{tr} W_n^{-2}/d)\,I$, so by (W3) the middle term has expected trace $\operatorname{tr}(\Lambda)/n^2 + O(n^{-3})$. For the last term, $|\operatorname{tr}(MB)| \le \|M\| \operatorname{tr} B$ for $B \succeq 0$; with $B = (\Lambda + W_n)^{-1} \preceq W_n^{-1}$ its trace is at most $\|\Lambda\|^2 \|W_n^{-1}\|^2 \operatorname{tr} W_n^{-1} \le d\,\|\Lambda\|^2 \operatorname{tr} W_n^{-3}$, whose expectation is $O(n^{-3})$ by (W3). Hence
\[
\E \operatorname{tr}(\Lambda + W_n)^{-1} = \frac{d}{n-d-1} - \frac{\operatorname{tr}\Lambda}{n^2} + O(n^{-3}),
\]
which is~\eqref{eq:extra} with $\kappa d$ replaced by $\operatorname{tr}\Lambda$. The proof of Corollary~\ref{cor:ess}(ii) with $p = 1$ then gives $\ess_n \to (\operatorname{tr}\Lambda - d\varepsilon)/d = k(c - \varepsilon)/d = (1-r)\,c\,k/d$.
\end{proof}
The same steps give the limit $(\operatorname{tr}\Lambda - d\varepsilon)/d$ for a reliable description with any Gaussian prior precision $\Lambda$: with many demonstrations in hand, a description is worth the precision it adds averaged over directions.

\subsection{Derivation of Equation \eqref{eq:trust} (The Fully Trusting Predictor)}\label{app:trust}
With no demonstrations the fully trusting predictor predicts $m^\top x$. With the moments of Step~3, $\E(w_i - m_i)^2 = a_0 - 2p(1-r)\,a_0 + (1-r)\,a_0 = \big(1 - (2p-1)(1-r)\big)\,a_0$, and summing over the $d$ coordinates gives~\eqref{eq:trust}; it exceeds $R^{\mathrm{demo}}(0) = a_0 d$ exactly when $p < 1/2$. With $n$ demonstrations it predicts $\mu_1^\top x$ whatever $Z$, where $\mu_1 = m + (cI + W_n)^{-1} X_n^\top (y_{1:n} - X_n m)$. As $r \to 0$ with $a_0$ and $n$ fixed, $c \to \infty$ and $\mu_1 \to m$ in mean square, so its error tends to $\E\|w - m\|^2$: $r a_0 d \to 0$ for a relevant description and $(2 - r)\,a_0 d \to 2 a_0 d$ for an irrelevant one, $2(1-p)\,a_0 d$ in all. Since $R^{\mathrm{demo}}(n) \to 0$, for every $p < 1$ there is an $n$ from which full trust does worse than no description once $r$ is small enough.

\paragraph{Prompt.} The user turn of the model's chat template:
\begin{quote}\scriptsize\ttfamily\raggedright
The numbers below are drawn from a normal distribution with standard deviation 60.\\
Its mean was drawn from a normal distribution with mean 510 and standard deviation 30.\\[3pt]
548\\
431\\[3pt]
Predict the next number. Reply with the number only.
\end{quote}

\noindent Without a description, the second sentence is ``Its mean is unknown.'' With a stated reliability, a third sentence follows: ``There is a 10\% chance that this statement is wrong, in which case the mean is unknown.'' With no demonstrations, the question is ``Predict the first number.'' The stated value of a relevant description is drawn given the task, so that $m \sim \mathcal{N}(500, 100^2 - \tau^2)$ and $w \mid m \sim \mathcal{N}(m, \tau^2)$; a task is redrawn in the rare case (under $1\%$) that a number or stated value falls outside $100$ to $999$.

\paragraph{Measurement.} The ESS of \S\ref{sec:llm} is Definition~\ref{def:ess} with squared error. Its summary leaves out $n = 0$, where without a description the models rarely answer with a number, and large $n$, where the ESS mixes the description's value with the models' slow learning (error $9$ to $23$ after $64$ demonstrations at $\sigma = 60$, against $7.5$ for the Bayes-optimal predictor) and their over-reliance on loose descriptions. A model that learns slowly from demonstrations values a description more in its own units; the weights do not depend on this. The no-description mean squared error at $n = 1$, $2$, $4$, \dots, $64$ is interpolated linearly in $\log n$, on the squared error, not its root; $\ess_n$ is the first $t$ at which that curve falls to the description's mean squared error at $n$, minus $n$. Since the curve starts at one demonstration, when one demonstration alone beats the description we report the bound $\ess_n \le 1 - n$. Each bootstrap replicate resamples tasks, the same tasks for both curves, and repeats the reading, so the intervals reflect sampling over tasks under this procedure, not the interpolation bias quantified next.

\paragraph{The Bayes-optimal reference.} The Bayes-optimal predictor is that of \S\ref{sec:llm}, with the mean uniform over $100$ to $999$, so that without a description its prediction is essentially the mean of the demonstrations shown (the range barely truncates it). A relevant description's exact Bayes-optimal ESS is then $c$, up to that truncation, that is $1$, $4$, and $36$. Computed the same way as the models' ESS, it reads $1.3$, $4.4$, and $36$ at $\sigma = 60$, and $1.2$, $4.7$, and $43$ at $\sigma = 30$: the $\log n$ interpolation biases it upward (by about $0.2$, $0.3$, and $1.8$ for $c = 1$, $4$, and $36$ with exact errors), and the finite sample of tasks shifts it further, in either direction (for $c = 36$, down to $36$ at $\sigma = 60$ and up to $43$ at $\sigma = 30$). The tables report the computed value for the Bayes-optimal predictor and the models alike. Under the prior the tasks are drawn from, $\mathcal{N}(500, 100^2)$, a predictor without the description would hold a prior precision of $\sigma^2/100^2 = 0.36$ demonstrations at $\sigma = 60$ ($0.09$ at $\sigma = 30$), and a relevant description's exact ESS would be $c - 0.36$, that is $0.64$, $3.64$, and $35.64$, the $(1-r)\,c$ of \S\ref{sec:specificity}. We keep the predictor that knows only what the prompt states, since the models are told nothing else.

\paragraph{Reading the curves.} Definition~\ref{def:ess} interpolates between the numbers of demonstrations at which the error is known, and the grid here doubles $n$, so how the curve is read between grid points matters. On the Bayes-optimal predictor's exact errors, $\sigma^2/n$ without the description and $\sigma^2/(c+n)$ with it, interpolation in $\log n$ overstates the ESS by $0.2$, $0.3$, and $1.8$ for $c = 1$, $4$, and $36$, and interpolation in $n$ by $0.3$, $0.6$, and $4.1$. For models answering without reasoning the first crossing is also the only one: of their twelve no-description curves at the two noise levels, only Phi-4's at $\sigma = 60$ rises, from $20.3$ at $32$ demonstrations to $20.4$ at $64$. Table~\ref{tab:sensitivity} gives the headline ESS under four readings: ours; interpolation in $n$; the curve made non-increasing by a least-squares monotone fit (pool adjacent violators); and the curve $A/(n + \kappa) + B$ fitted to the no-description errors by relative least squares, the form of a Bayesian learner's error plus a floor, which recovers the exact ESS from the Bayes-optimal predictor's exact errors. No model's headline ESS moves by more than $1.4$ demonstrations, and none exceeds $8.1$ for the $c = 36$ description, against $35$ to $38$ for the Bayes-optimal predictor. The readings differ more at larger $n$, where a model's no-description curve flattens and a small difference in error spans many demonstrations: gpt-oss-20b's $c = 36$ ESS at $n = 8$ is $17$ in Table~\ref{tab:llm-worth} and $9.2$ from the fitted curve. In Figure~\ref{fig:curves}, the error of four models with the $c = 36$ description rises from one demonstration shown to two, because each demonstration pulls their prediction off the stated value much more than it pulls the Bayes-optimal prediction (Table~\ref{tab:llm-full}).

\paragraph{A frontier model inside an agent harness.} The models above are open ones run locally, so that their first-token distributions can be read. The squared-error ESS needs only answers, so we also put the prompts of three relevant descriptions ($c = 1$, $4$, $36$; $\sigma = 60$) with $n = 1$ and $4$ demonstrations, $100$ tasks each, to GPT-5.6-Luna (model \texttt{gpt-5.6-luna}) through the Codex command-line agent in its read-only sandbox, on a subscription, once with its reasoning effort set to low (about $115$ reasoning tokens per answer) and once with reasoning off. This measures the model as deployed in that agent: its instructions and tool definitions, about $26{,}000$ tokens, surround the prompt, as a provider's system prompt surrounds it through an API. The model used no tool in any of these $1{,}200$ replies, and every reply is a number alone (ten with a trailing period; $181$ with a decimal part, which we keep).

With reasoning, the weight on the stated value is the Bayes-optimal $c/(c+n)$ to within $0.03$ in all six cells, the implied worth $n\,a/b$, with $a$ and $b$ the weights on the stated value and on the demonstrations' mean, is $c$ to within half a demonstration (Table~\ref{tab:agent}), and the error matches the Bayes-optimal predictor's to within $0.8$. The prompt therefore contains what is needed to reach the Bayes-optimal weight, and this model reaches it when it reasons. With reasoning off, the same model shows the flat weight of \S\ref{sec:llm}: $0.72$ to $0.88$ at $n = 1$ and $0.40$ to $0.47$ at $n = 4$ whatever the stated specificity, and an implied worth of $2.6$ to $5.8$ demonstrations for descriptions worth $1$ to $36$.

A more accurate no-description curve lowers the ESS read from it, so the tool use does not inflate the ESS. With reasoning, the ESS of the three descriptions at $n = 1$ and $4$ matches the Bayes-optimal predictor's, read the same way from its predictions on the same tasks, to within $0.2$ demonstrations for $c = 1$ and $4$ and $32$ against $33$ for $c = 36$ (Table~\ref{tab:agent-ess}; with $100$ tasks the reading itself moves the Bayes-optimal $4$ to $2.4$ and $2.9$). With reasoning off, the $c = 36$ description is worth $5.4$ demonstrations at $n = 1$ and $1.3$ at $n = 4$, in the range of the open models of \S\ref{sec:llm}, and the $c = 1$ description hurts at $n = 4$.
