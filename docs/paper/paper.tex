\begin{abstract}
A prompt to a language model usually contains a task description and some examples. Theories of in-context learning (ICL) explain what the examples do but not what the description adds, or how the two trade off. We treat ICL as Bayesian inference over a latent task, so that examples are data and a description sets the prior, and we measure a description's worth as its \emph{effective sample size}: the number of examples that give a Bayes-optimal learner the same prediction regret. In a testbed where the optimal learner is exact, in-context linear regression, we compute this worth as a function of a description's \emph{precision} (how narrowly it constrains the task) and \emph{reliability} (how often it is correct). Three findings. First, a description is worth more examples for a single prediction than for a long session with feedback, by up to 8.5$\times$ on our grid; the long-horizon worth equals the description's information content, and the gap is geometric: a description narrows every direction of the task while examples narrow only the directions they cover. Second, reliability caps the worth of precision: a description that is wrong one time in ten gains little from being made fifty times more precise, whereas a reliable one gains sixfold. Third, for precise but unreliable descriptions the ordering reverses, and the description is worth more over a long session than for a single prediction, because feedback lets the learner check it. \todo{Fourth, on the trained networks, once obtained.} All claims concern Bayes-optimal predictors and small meta-trained sequence models, not large language models.
\end{abstract}

\section{Introduction}

Theories of in-context learning have mostly studied prompts made only of input--output examples \citep{garg2022,akyurek2023,xie2022,genewein2025}. Real prompts usually contain more: a natural-language task description together with the examples \citep{brown2020}. Example-only theories cannot say what the description adds, or how it trades off against the examples, and the empirical record points both ways. A prompt can be worth hundreds of labelled examples \citep{lescao2021,honda2025}, yet models also discount instructions: enough examples override an explicitly stated bias \citep{gupta2025}, and misleading instructions can work about as well as good ones \citep{webson2022}. Theory has begun to include instructions \citep{huangge2025,lin2025,tong2026} but does not yet say how many examples an instruction is worth.

We give a Bayesian answer. If ICL is Bayesian inference over a latent task \citep{xie2022}, examples are data and the description sets the prior. Bayesian statistics already measures what a prior is worth in data: its effective sample size, the number of observations the prior is equivalent to \citep{morita2008}. A prior's worth depends on how concentrated it is and on whether it is right \citep{evans2006}, and the same two properties describe an instruction:
\begin{itemize}
  \item \textbf{Precision:} how narrowly the description constrains the space of tasks.
  \item \textbf{Reliability:} how often the description is correct.
\end{itemize}

We compute a description's worth as a function of both, in a setting where the Bayes-optimal learner is exact: in-context linear regression \citep{garg2022,akyurek2023} with a Gaussian prior on the task whose mean and variance a description sets, and a robust mixture prior \citep{schmidli2014} when the description may be wrong. We define worth through prediction, as the number of examples whose cumulative regret over the next $N$ predictions equals the description's, and we ask how it depends on the horizon $N$.

\paragraph{Contributions.}
\begin{enumerate}
  \item A definition of a description's worth in examples through prediction regret at a chosen horizon (\S\ref{sec:setting}). Prediction-based effective sample sizes were left open in the statistics literature \citep{reimherr2021,neuenschwander2020}; ours is exact in the linear-Gaussian setting.
  \item For reliable descriptions, the single-prediction worth exceeds the long-horizon worth (\S\ref{sec:reliable}). The long-horizon worth is the examples carrying the same information as the description, a consequence of \citet{clarke1990}; the single-prediction worth is larger because a description shrinks uncertainty in every direction and examples do not. Both have closed forms in the proportional limit through the Marchenko--Pastur law \citep{tulino2004}. The ratio grows with dimension and signal-to-noise ratio and reaches 8.5 on our grid.
  \item For unreliable descriptions, the regret splits into a Gaussian term and an identification term (\S\ref{sec:unreliable}). Reliability caps the worth of precision for a single prediction; over a long horizon the worth is unbounded in precision, so the horizon ordering reverses for precise, unreliable descriptions. Mis-set trust costs $\KL(p\,\|\,q)$ nats over a long horizon, and a wrong description is abandoned after one to three examples.
  \item \todo{Meta-trained Transformers: whether their worth in examples and their trust match the Bayes-optimal learner (\S\ref{sec:networks}). Results pending.}
\end{enumerate}

\section{Related work}

\paragraph{Bayesian views of ICL.} \citet{xie2022} explain ICL as implicit Bayesian inference over a latent concept. In linear regression, transformers trained on Gaussian tasks track the Bayes-optimal (ridge) predictor \citep{akyurek2023,raventos2023,panwar2024}, and \citet{lu2025} give the proportional-limit error of linear attention through random matrix theory. \citet{jeon2024} decompose the average cumulative log loss of ICL by mutual information; \citet{genewein2025} score small meta-trained networks against the Bayes-optimal predictor by cumulative log-loss regret, which we adopt. None of these prices a prior in examples or compares horizons.

\paragraph{Instructions in ICL theory.} \citet{huangge2025} add a task descriptor to in-context linear regression, the mean of the inputs, and show that linear attention uses it to centre the inputs. Their descriptor carries no information about the mapping, so a Bayes-optimal learner values it at zero examples; ours describes the weights. \citet{lin2025} give a hypothesis class as a prefix and observe that it helps at a fixed number of examples. \citet{tong2026} show that a single incorrect instruction is overridden at an exponential rate in the number of demonstrations, without a reliability parameter. \citet{lin2024} study a Gaussian-mixture task prior, whose posterior is the same conjugate computation as ours, and show that a misleading prior hurts early and washes out. \citet{zhu2026} train transformers on a prefix of earlier datasets and find Bayes-optimal use of it. Empirical exchange rates exist for fine-tuning \citep{lescao2021,cook2025} and for distilled many-shot prompts \citep{honda2025}, not for ICL with a Bayes-optimal benchmark.

\paragraph{Prior effective sample size.} \citet{morita2008} define a prior's ESS by matching its curvature to that of a posterior from a flat prior; \citet{reimherr2021} define it through prior--data discrepancy and name a prediction-based version as an open problem; \citet{neuenschwander2020} require consistency of expected posterior ESS and treat one-parameter models. \citet{clarke1996} and \citet{lin2007} define an information-theoretic prior sample size by relative entropy. Robust mixture priors \citep{schmidli2014} and their ESS under conflict \citep{wiesenfarth2020} come from clinical trials with historical controls. Closest to our unreliable case, \citet{reznik2026} derive the optimal exponent of a power prior under predictive log loss and cap the borrowed sample size by the discrepancy; that ESS is the exponent times the historical sample size, does not depend on the horizon, and has no mixture. Ours is defined by matching regret against examples, depends on the horizon, and treats a two-component mixture.

\section{Setting}\label{sec:setting}

\paragraph{Task.} A task is a weight vector $w\in\mathbb{R}^d$. An example is an input $x\sim\mathcal{N}(0,I_d)$ and an answer $y=w^\top x+\epsilon$, $\epsilon\sim\mathcal{N}(0,\sigma_y^2)$. Without a description, $w\sim\mathcal{N}(0,s_0^2 I_d)$. We set $\sigma_y=1$ and write $a_0=s_0^2/\sigma_y^2$ for the base signal-to-noise ratio.

\paragraph{Description.} A description is a vector $m\in\mathbb{R}^d$ and a variance $s_\ell^2=r\,s_0^2$, $r\in(0,1)$: if it is correct, $w\sim\mathcal{N}(m,s_\ell^2 I_d)$. Smaller $r$ is a more precise description. We draw $m\sim\mathcal{N}(0,(1-r)s_0^2 I_d)$, so that $w$ has the same marginal law with or without a description; this is the hierarchical prior of the proposal, coarse descriptions naming a task family and precise ones nearly stating the rule. A description is correct with probability $p$ and otherwise describes an unrelated task, $w\sim\mathcal{N}(0,s_0^2I_d)$ independently of $m$. The Bayes-optimal prior is the robust mixture $p\,\mathcal{N}(m,s_\ell^2I)+(1-p)\,\mathcal{N}(0,s_0^2I)$ \citep{schmidli2014}. A description is idealised as a vector, not text: the learner must learn how much to weigh it, not how to parse it.

\paragraph{Scoring.} The learner predicts a distribution for each of the next $N$ answers, seeing each true answer before the next prediction. Its regret $R_N$ is its cumulative log loss minus that of an oracle that knows $w$, in nats \citep{genewein2025}. $N=1$ is a single question; large $N$ is a session with feedback.

\begin{definition}[Worth in examples]
Let $R^{\mathrm{desc}}_N$ be the regret of the learner with the description and no examples, and $R^{\mathrm{ex}}_N(n)$ the regret of the learner with $n$ examples and no description, both averaged over tasks and inputs. The description's effective sample size at horizon $N$ is the $n$ (interpolated between integers) at which $R^{\mathrm{ex}}_N(n)=R^{\mathrm{desc}}_N$.
\end{definition}

The comparison learner uses the base prior, so it is the same Bayes-optimal learner with less information. The definition follows \citet{reimherr2021} in matching a prior against observations and differs in matching prediction regret at a horizon rather than a posterior functional.

\section{Reliable descriptions: worth depends on the horizon}\label{sec:reliable}

For $p=1$ everything reduces to one function. Under a Gaussian prior with signal-to-noise ratio $a$, the posterior covariance after inputs $X_k\in\mathbb{R}^{k\times d}$ is $\sigma_y^2(I/a+X_k^\top X_k)^{-1}$ and does not depend on $m$ or on the answers, and log-loss regret obeys the chain rule, so with
\begin{equation}
  G_a(k)=\tfrac12\,\E\log\det\!\big(I+aX_k^\top X_k\big),
\end{equation}
the description's regret over horizon $N$ is $G_{a_\ell}(N)$ with $a_\ell=r a_0$, and the regret after $n$ examples is $G_{a_0}(n+N)-G_{a_0}(n)$.

\begin{proposition}[Long horizon]\label{prop:long}
As $N\to\infty$, $\ess_N\to n^\star$, the number of examples whose expected information gain equals the description's: $G_{a_0}(n^\star)=\tfrac{d}{2}\log(1/r)$.
\end{proposition}
This follows from the redundancy asymptotics of \citet{clarke1990}: cumulative log-loss regret is the mutual information between the answers and $w$, and both learners' regrets grow as $\tfrac d2\log N$ with a constant offset equal to the information each lacked at the start. In the long run a description is worth exactly the uncertainty it removes.

\begin{proposition}[Single query]\label{prop:single}
$\ess_1\ge\ess_\infty$, with equality in $d=1$ up to the variability of single examples, and exactly under balanced designs $X^\top X\propto I$.
\end{proposition}
The single-query regret is $\tfrac12\E\log(1+x^\top\Sigma x)$ for posterior covariance $\Sigma$, which depends on the trace of $\Sigma$ (A-optimality), while the information depends on its log-determinant (D-optimality). A description shrinks every eigenvalue by the same factor; $n<d$ random examples shrink $n$ directions almost to zero and leave the rest untouched. By the AM--GM inequality the isotropic shrinkage gives lower trace at equal log-determinant, so it takes more examples to match the description for a single prediction than for information. The inequality is classical; the contribution is its size, which we now quantify. At high signal-to-noise ratio and $n<d$, $\ess_1\approx d(1-r)$: a description that removes a fraction $1-r$ of the prior variance is worth that fraction of $d$ examples.

\begin{proposition}[Proportional limit]\label{prop:mp}
As $d,n\to\infty$ with $n/d=\gamma$ and $d\,a_0=\rho$ fixed, $\ess_1/d$ solves $\eta(\gamma)=r$ and $\ess_\infty/d$ solves $\mathcal V(\gamma)=\log(1/r)$, where $\eta$ and $\mathcal V$ are the $\eta$- and Shannon transforms of the Marchenko--Pastur law \citep[eqs.~2.52, 2.62]{tulino2004}.
\end{proposition}
These match the simulation to within about 2\% at $d=64$.

\section{Unreliable descriptions}\label{sec:unreliable}

Let the learner assume reliability $q$ when the truth is $p$. Its marginal likelihood is $q\,\mathrm{ML}_1+(1-q)\,\mathrm{ML}_0$ in terms of the two Gaussian components, so with $c$ the true component and $\pi_c(k)$ the learner's posterior weight on it after $k$ observations,
\begin{equation}
  R_N = \E\Big[\tfrac12\textstyle\sum\text{information gains of the true component}\Big] + \E\big[\log\pi_c(n+N)-\log\pi_c(n)\big],
\end{equation}
a Gaussian term as in \S\ref{sec:reliable} plus an identification term: the expected rise in the log posterior weight of the truth. Over a long horizon the identification term tends to the cross-entropy $H(p,q)$, so mis-set trust costs $\KL(p\,\|\,q)$ nats, independent of $d$; this is the wrong-prior penalty of universal coding \citep{cover2006}. We validate the split against the joint Gaussian likelihood and against $\KL(p\,\|\,q)$: at $p=0.7$, $q=0.999$, $d=16$, the long-horizon excess is 1.46 nats, as predicted.

\paragraph{Long-horizon worth.} Combining the split with Proposition~\ref{prop:long}: as $N\to\infty$ the description is worth the examples whose information gain is
\begin{equation}
  p\,\tfrac d2\log(1/r) - H(p),\label{eq:longmix}
\end{equation}
the reliability-weighted information minus the entropy of not knowing whether the description is right. \todo{Derivation to be written out; verified numerically at one point ($d=16$, $a_0=10$, $r=0.05$, $p=0.9$: 9.2 predicted, 9.22 computed).} It is unbounded in precision.

\paragraph{Single-query worth.} With no examples, the learner cannot tell whether the description is right, so its predictive is the $p$-mixture of the two components' predictives and its regret has a floor of about $(1-p)$ times the no-description regret. The worth therefore saturates as $r\to0$.

\paragraph{Reliability caps the worth of precision.} In Table~\ref{tab:rq2}, making the description fifty times more precise ($r$ from 0.05 to 0.001) raises the single-query worth from 16.9 to 116.5 examples when it is reliable, but only from 14.8 to 23.1 when it is right nine times in ten. Being wrong one time in a hundred already halves the worth of the most precise description (64.2 at $p=0.99$). This holds in all four settings we computed ($d\in\{4,16,64\}$, $a_0\in\{10,100\}$).

\paragraph{The horizon ordering reverses.} For the precise, unreliable description the long-horizon worth (49.8) exceeds the single-query worth (23.1), the opposite of \S\ref{sec:reliable}: with feedback the learner can check the description and then exploit its full precision, whereas for a single prediction it must hedge. The reversal holds in three of our four settings and fails at $d=16$, $a_0=100$, so it is conditional. \todo{Derive the boundary from equation~\eqref{eq:longmix} and the single-query floor.}

\paragraph{Trust is cheap to mis-set, except at the extreme.} At $d=16$, $r=0.001$, $p=0.7$, the single-query regret is 1.27 nats with calibrated trust, 1.95 at $q=0.1$, 1.90 at $q=0.99$, 2.51 when the description is ignored, and 40.5 at $q=1$. Over a long horizon the excess follows $\KL(p\,\|\,q)$ and stays below 1.5 nats for any $q\in[0.1,0.999]$. A Bayes-optimal learner therefore loses little from imperfect trust unless it trusts completely.

\paragraph{Tipping points.} A wrong description is abandoned (posterior weight below $1/2$) after a median of one to three examples for $r\le0.05$ at every trust level up to $q=1-10^{-6}$; coarse descriptions ($r=0.5$) take up to 23 examples at $d=64$. This is far faster than the tens of examples reported for language models \citep{camassa2026}, which we return to in \S\ref{sec:discussion}.

\section{Discussion}\label{sec:discussion}

\paragraph{What the results say.} A description's worth is not one number. For a single answer, the usual way a prompt is used, it is worth more than its information content, and by a factor that grows with the size of the task. Over a session with feedback it is worth exactly its information. Unreliability changes which of these is larger: a precise description that might be wrong is worth little for one answer, because the learner must hedge, and much more once the answers let it check. Precision only pays when the description can be trusted or tested.

\paragraph{Relation to language models.} Our learner is Bayes-optimal and our description is a vector; language models are neither. The published record supports two of our qualitative predictions, a tipping point under conflicting examples and lower trust in models whose training text made instructions unreliable \citep{gupta2025,camassa2026,bigelow2025}, and says nothing yet about saturation or the horizon. Two disagreements are instructive: language models accumulate evidence sublinearly \citep{bigelow2025}, and they tip after tens of examples where the exact learner tips after one to three, so a quantitative match would need discounted examples. Whether small meta-trained networks match the exact learner is the question of \S\ref{sec:networks}.

\paragraph{Limitations.} The description is a vector, not text; the model must weigh it, not parse it. The setting is linear regression with Gaussian inputs, chosen because the optimal learner is exact. The results for unreliable descriptions are computed, with derivations for the long-horizon limit and the trust cost; the boundary of the horizon reversal is not yet derived. \todo{Network results pending.}
