\begin{abstract}
Prompts combine a task description with in-context examples, but theories of in-context learning (ICL) model only the examples. Under the Bayesian account of ICL, the examples are observations and the description is the prior, and Bayesian statistics measures a prior by its effective sample size (ESS): the number of observations it is equivalent to. We define the ESS of a task description as the number of in-context examples at which a Bayes-optimal predictor attains the same one-step log-loss regret as it attains from the description alone, and compute it in in-context linear regression, where the Bayes-optimal predictor is exact, as a function of the description's precision and reliability. Two results. A reliable description that removes a fraction $1-r$ of the prior variance is worth about $d(1-r)$ examples in a $d$-dimensional task. An unreliable description, correct with probability $p$, has a regret floor of $(1-p)$ times the no-description regret plus the entropy of $p$, so its ESS saturates in precision: at $p=0.9$, a fiftyfold increase in precision adds a few examples where a reliable description gains a hundred. \todo{Third, whether meta-trained Transformers reproduce these numbers.} Our claims concern Bayes-optimal predictors and small meta-trained sequence models, not large language models.
\end{abstract}

\section{Introduction}

Theoretical work on in-context learning has modelled prompts as input--output examples alone \citep{garg2022,akyurek2023,xie2022,genewein2025}. Prompts in practice also carry a natural-language task description \citep{brown2020}, and the empirical record on its value is inconsistent: a description can substitute for hundreds of labelled examples \citep{lescao2021,honda2025}, yet models also discount instructions in favour of examples \citep{gupta2025,webson2022}. Recent theory admits descriptions into the model \citep{huangge2025,lin2025,tong2026} but does not express their value on the scale of the examples they accompany.

We propose that scale. Under the Bayesian account of ICL \citep{xie2022}, a sequence model approximates the posterior predictive for a latent task: the in-context examples are observations and the task description specifies the prior. Bayesian statistics measures a prior on the scale of observations by its \emph{prior effective sample size} \citep{morita2008}, and two properties of a prior govern that measure: how concentrated it is, and whether it is compatible with the data \citep{evans2006}. A task description has the same two properties, which we call its \textbf{precision}, the posterior contraction it induces, and its \textbf{reliability}, the prior probability that it is correct, modelled with a robust mixture prior \citep{schmidli2014}.

We compute the ESS of a description as a function of both in in-context linear regression \citep{garg2022}, where the Bayes-optimal predictor is available in closed form, for a single prediction, the ordinary use of a prompt.

\paragraph{Contributions.}
\begin{enumerate}
  \item A definition of the ESS of a task description by matching one-step log-loss regret against in-context examples (\S\ref{sec:setting}). A prediction-based ESS was posed as an open problem by \citet{reimherr2021}; in the linear-Gaussian setting ours is exact.
  \item For reliable descriptions, $\ess\approx d(1-r)$ (\S\ref{sec:precision}).
  \item For unreliable descriptions, the regret has a floor of $(1-p)$ times the no-description regret plus $H(p)$, so the ESS saturates in precision (\S\ref{sec:reliability}).

\end{enumerate}

\section{Related work}

\paragraph{Bayesian ICL.} \citet{xie2022} derive ICL as implicit Bayesian inference over a latent concept. In linear regression, Transformers meta-trained on Gaussian tasks track the Bayes-optimal ridge predictor \citep{akyurek2023,raventos2023,panwar2024}, and \citet{genewein2025} evaluate small meta-trained networks by log-loss regret against the Bayes-optimal predictor, the criterion we adopt. None of these expresses a prior on the scale of in-context examples.

\paragraph{Task descriptions in ICL theory.} \citet{huangge2025} add a descriptor token to in-context linear regression, the mean of the input distribution, and show that linear self-attention uses it to centre the inputs. That descriptor is independent of the regression weights, so a Bayes-optimal predictor assigns it zero ESS; ours specifies the prior on the weights. \citet{lin2025} supply a hypothesis class as a prefix; \citet{tong2026} show that an incorrect instruction is overridden at an exponential rate in the number of demonstrations, without a reliability parameter; \citet{lin2024} analyse a Gaussian-mixture task prior, whose posterior is the same conjugate computation as ours.

\paragraph{Prior effective sample size.} \citet{morita2008} define the ESS of a prior by curvature matching and \citet{reimherr2021} by prior--likelihood discordance, naming a prediction-based measure as open. Robust mixture priors \citep{schmidli2014} arise in clinical trials with historical controls, where the informative component may conflict with the data.

\section{Setting}\label{sec:setting}

\paragraph{Task distribution.} A task is a weight vector $w\in\R^d$. An in-context example is an input $x\sim\mathcal N(0,I_d)$ with label $y=w^\top x+\epsilon$, $\epsilon\sim\mathcal N(0,\sigma_y^2)$. The base prior is $w\sim\mathcal N(0,s_0^2I_d)$. We set $\sigma_y=1$ and write $a_0=s_0^2/\sigma_y^2$ for the prior signal-to-noise ratio.

\paragraph{Task description.} A description is a vector $m\in\R^d$ with a variance $s_\ell^2=rs_0^2$, $r\in(0,1)$, the \emph{precision ratio}; conditional on the description being correct, $w\sim\mathcal N(m,s_\ell^2I_d)$. It is generated hierarchically, $m\sim\mathcal N(0,(1-r)s_0^2I_d)$, so that the marginal law of $w$ is the base prior whether or not a description is present. The description is correct with probability $p$, its \emph{reliability}; otherwise $w\sim\mathcal N(0,s_0^2I_d)$ independently of $m$. The Bayes-optimal prior given a description is the robust mixture $p\,\mathcal N(m,s_\ell^2I)+(1-p)\,\mathcal N(0,s_0^2I)$ of \citet{schmidli2014}. The description idealises an instruction as a vector: the learner must weight it, not parse it.

\paragraph{Regret.} The predictor outputs a predictive distribution for the label of one query $x$. Its regret is its expected log loss minus that of the oracle that knows $w$, in nats \citep{genewein2025}, the expectation over tasks, inputs, and labels.

\begin{definition}[Effective sample size of a description]
Let $R^{\mathrm{desc}}$ be the regret of the Bayes-optimal predictor conditioned on the description and no examples, and $R^{\mathrm{ex}}(n)$ that of the Bayes-optimal predictor under the base prior conditioned on $n$ examples. The ESS of the description is the $n$, interpolated linearly between integers, at which $R^{\mathrm{ex}}(n)=R^{\mathrm{desc}}$.
\end{definition}

Both predictors are the same Bayes-optimal predictor with different conditioning information, so the ESS is a statement about information rather than about a learner.

\section{Precision}\label{sec:precision}

For a reliable description ($p=1$) the posterior covariance of $w$ after inputs $X_n\in\R^{n\times d}$ under a Gaussian prior with signal-to-noise ratio $a$ is $\Sigma=\sigma_y^2(I/a+X_n^\top X_n)^{-1}$, independent of $m$ and of the labels, and the one-step regret is $\tfrac12\E\log(1+x^\top\Sigma x)$. The description alone has $a=ra_0$ and $n=0$; the examples have $a=a_0$.

\begin{proposition}\label{prop:precision}
At high signal-to-noise ratio and for $\ess<d$, $\ess\approx d(1-r)$.
\end{proposition}
\emph{Sketch.} With $n<d$ examples at high signal-to-noise ratio, the posterior variance is near zero along the $n$ observed directions and $s_0^2$ along the other $d-n$, so $x^\top\Sigma x\approx s_0^2\|x_\perp\|^2$ with $\|x_\perp\|^2\sim\chi^2_{d-n}$ and the regret is about $\tfrac12\log(a_0(d-n))$. The description contracts every direction to $rs_0^2$, giving about $\tfrac12\log(ra_0d)$. Equating, $d-n=rd$. \todo{Write out with the error term.}

\section{Reliability}\label{sec:reliability}

Given an unreliable description and no examples, the Bayes-optimal predictive distribution is the $p$-mixture of the two components' predictives, because nothing has been observed that could identify the correct component.

\begin{proposition}\label{prop:floor}
As $r\to0$, the regret of a description with reliability $p$ tends to $(1-p)\,R^{\mathrm{ex}}(0)+H(p)$, where $H(p)$ is the binary entropy and $R^{\mathrm{ex}}(0)$ the regret with neither description nor examples.
\end{proposition}
\emph{Sketch.} As $r\to0$ the two components' predictives separate: under a correct description the mixture assigns the label density $p$ times the oracle's, costing $\log(1/p)$; under an incorrect one it assigns $(1-p)$ times the base predictive's, costing $R^{\mathrm{ex}}(0)+\log(1/(1-p))$. Since $R^{\mathrm{ex}}(n)$ is decreasing in $n$, the ESS of an unreliable description is bounded by the $n$ at which $R^{\mathrm{ex}}(n)$ reaches this floor, however precise the description.

A reliability of $0.99$ already halves the ESS of the most precise description. The same pattern holds at $d\in\{4,64\}$ and $a_0=100$.

\section{Discussion}

A task description is worth a definite number of in-context examples to a Bayes-optimal predictor, and that number has a simple form: the fraction of the prior variance the description removes, times the dimension of the task, provided the description can be trusted. Reliability caps what precision can buy, because a predictor that cannot yet tell whether the description is correct must hedge between it and the base prior, and the cost of hedging does not shrink as the description sharpens.

\paragraph{Limitations.} Our claims concern Bayes-optimal predictors and small meta-trained sequence models, not language models. The description is a vector rather than text, and the setting is linear regression with Gaussian inputs, chosen because the Bayes-optimal predictor is exact. The ESS is defined for a single prediction; with sequential feedback the predictor can identify whether a description is correct, and the ESS changes with the prediction horizon, which we leave to future work. \todo{Network results pending.}
