\chapter{Language-Model Results at Every Number of Demonstrations}\label{app:llm-tables}

This appendix reports the $2{,}000$-task run of Chapter~\ref{ch:llm}, without reasoning, at every evaluated demonstration count. Tables~\ref{tab:llm-worth} and~\ref{tab:llm-worth-written} report ESS for the distribution-readout and written-readout models, and Table~\ref{tab:llm-full} reports description weights for the distribution-readout models. Tables~\ref{tab:llm-worth} and~\ref{tab:llm-full} each continue onto a second page.
