\chapter{Language-Model Results at Every Number of Demonstrations}\label{app:llm-tables}

This appendix collects the language-model tables of Chapter~\ref{ch:llm} at every number of demonstrations. Tables~\ref{tab:llm-worth} and~\ref{tab:llm-worth-written} report ESS at every evaluated demonstration count, and Table~\ref{tab:llm-full} reports description weights for the models with a distribution readout. Tables~\ref{tab:llm-worth} and~\ref{tab:llm-full} each continue onto a second page.
